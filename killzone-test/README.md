# Килл-зоны против всех окон той же длины

Быстрый старт:

```bash
python killzone_test.py
```

Скрипт ожидает файл с минутными данными ES. Подробности в methodology.md.

Основной результат: продолжение движения во всех семи окнах лежит
в районе 50 процентов (от 44.9 до 51.2). Два окна выделяются по величине
хода, и оба накрывают кластер публикаций статистики в 10:00.
